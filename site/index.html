The problem

AI writes the code. You still have to own it.

Tools like Cursor, Claude and ChatGPT can build an app in an afternoon. A month later it has a hundred files, and asking for one small change means guessing which files to paste and hoping nothing else breaks.

CodeBase reads the project for you. It sorts every file into plain categories, finds the features that run through them, remembers what each file is for, and keeps the map current while you and your AI keep changing things.

What you get

Know how your project works, not just where its files are.

  1. 01

    The architecture, not the folders

    Every file gets the part it plays: screen, API client, route, controller, model; or scenario, step definition, page object, driver, hook. Read from what the code does, so feature folders and messy layouts still come out right.

  2. 02

    Every journey, end to end

    Log in, request a ride, assign a driver, pay. Each flow is traced from the first screen or test step through the server to the data, in the order people use the app. Press play and watch it move.

  3. 03

    A tree that stays still

    Project, parts, files, as a real tree in 3D or 2D, with the parts in the order data moves through them. Nothing floats; click a part to open it.

  4. 04

    Every version, in plain words

    What each commit changed in the design, the design at any past version next to today's, and what a file change would break before you make it.

Step 1

Open a project

Pick a folder or paste a GitHub link. Dependencies, build output and anything in .gitignore are skipped.

Step 2

Teach it once

One copy-paste with any AI chat gives every main folder a plain description that stays tied to the code.

Step 3

Ask for changes

Write what you want, confirm the files, paste the prompt. The map shows exactly what changed afterwards.

Ask AI

From "make it do this" to a prompt an engineer would write.

Every prompt has a role, the project context, what each file does, your task, how you will know it worked, and rules that stop the AI from guessing or skipping code. Turn on plain-language mode and the answer comes back with step-by-step instructions.

<role>
You are a senior Laravel and PHP engineer and a patient
teacher, helping someone who builds apps with AI tools.
</role>

<what_these_files_do>
- app/Models/Invoice.php (Data, Model): One invoice record.
- app/Http/Controllers/InvoiceController.php (Server & API,
  Controller): Saves and lists invoices.
</what_these_files_do>

<task>
Add a due date to invoices and show it in the list.
</task>

<rules>
- If you need a file I have not given you, reply
  "NEED FILES: …" and stop. Never guess its contents.
</rules>
… plus the code, done-when and answer format
Under the hood

A single fast program that stays on your computer.

EngineWritten in Rust. One executable with the whole interface built in. No Node.js, Python or database to install.
PrivacyRuns on localhost. Your code is never uploaded. Prompts go nowhere until you paste them yourself.
Live updatesWatches the folder and rescans only changed files, so the map follows your edits within a second.
UnderstandsLaravel and PHP (PSR-4, Blade views and components), JavaScript, TypeScript, Vue, React, Python, Rust, CSS and HTML links. Other languages get structure and summaries.
MemoryDescriptions live in .codebase/ inside the project, so they travel with the repository. Edited files are flagged until their description is confirmed.
LimitsLinks are found by pattern matching, not by running your code, so some framework magic stays invisible. Projects above 8,000 files are cut off.
